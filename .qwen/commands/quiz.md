Тема проверки: {{args}}

Проведи проверку знаний по этой теме, строго следуя skill `quiz`:

- Задавай вопросы через `ask_user_question` (2–4 варианта, правильный ответ держи в уме и не раскрывай).
- Варианты — голые утверждения без обоснований; строй дистракторы мутацией правильного утверждения.
- Меняй позицию правильного варианта между вопросами.
- После каждого ответа — короткая обратная связь: ✓/✗ + правильный вариант + объяснение.
- Начинай с вопросов среднего уровня и адаптируй сложность по ответам: верно — резко усложняй, неверно — зондируй вокруг промаха, чтобы понять его вид.

Если тема не указана — сначала спроси её через `ask_user_question`. Если в проекте есть журнал (`.qwen/learn-active-log`) — дописывай блоки вопрос-ответ в него по правилам skill `learn-log`.
