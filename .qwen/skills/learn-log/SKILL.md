# Журнал занятий

Терминал плохо подходит для чтения длинных объяснений, markdown и математики. Поэтому уроки зеркалируются в markdown-файл, который потом читается отрендеренным (например, в Obsidian) — там нативно рендерятся `$...$`-формула, блоки кода и markdown.

В журнал попадает только то, что важно для чтения:
- промпты пользователя;
- текст урока (твои ответы);
- блоки вопрос-ответ (`ask_user_question`/`quiz`).

Служебное (вызовы инструментов, чтение/запись файлов, рендер картинок) — не попадает.

## Активный журнал

Путь активного журнала хранится в `.qwen/learn-active-log`. Управление — через `scripts/log.mjs`:

```bash
node scripts/log.mjs current        # напечатать активный файл (пусто, если не задан)
node scripts/log.mjs init <тема>    # создать lessons/<слаг>.md и сделать активным
node scripts/log.mjs set <путь>     # задать произвольный файл активным
```

**В начале учебной сессии** выполни `node scripts/log.mjs current`. Если вывод пуст — создай журнал под тему: `node scripts/log.mjs init "<тема>"`.

## Как дописывать

После каждого содержательного хода сформируй блок в markdown и допиши его в конец активного журнала (append-only, прошлое никогда не переписывается):

```bash
node scripts/log.mjs append <<'MD'
> [!quote] Вы

<промпт пользователя>

> [!abstract] Учитель

<текст урока>

> [!question] Вопрос

<вопрос и варианты>

> [!success] Ответ

<выбор пользователя и обратная связь>
MD
```

Формат блока:
- Промпт пользователя — callout `[!quote] Вы`.
- Твой урок — callout `[!abstract] Учитель`.
- Вопросы — callout `[!question] Вопрос` с вариантами (правильный ответ в журнал НЕ пишется до ответа пользователя); ответ и обратная связь — `[!success]` при верном и `[!failure]` при неверном.
- Заголовок темы (`## Тема`) добавь один раз, при первом блоке.

Осторожно с heredoc: содержимое между `<<'MD'` и `MD` не раскрывается (кавычки вокруг `MD` — обязательны). Если урок содержит строку `MD` на отдельной строке — выбери другой разделитель (например `MDEND`).

## Правила

- Только append: не редактируй и не удаляй уже записанное.
- LaTeX пиши как есть (`$f(x)$`, `$$ ... $$`) — рендер на стороне Obsidian, здесь ничего размечать не надо.
- Не дублируй служебные сообщения и не логируй сам факт логирования.
- Картинки вставляются как `![](viz/<файл>.png)` — Obsidian отрендерит их по относительному пути.

## Команды

- `/mdlog <путь>` — задать активный журнал.
- `/mdlog` без аргумента — показать текущий активный журнал.

Связь с обучением: полный протокол сессии — в skill `teach`; ведение журнала встроено в него на каждом содержательном ходу.
